Google OAuth & YouTube

Google obtains user consent. YouTube Data API creates and manages Live broadcasts and processes user-selected video uploads.

Authorization boundary: StecStats receives scoped OAuth authorization only after Google consent. It never receives the user’s Google password. HTTPS + encrypted token storage
Coach-initiated onlyBroadcast creation, completion, and uploads require an explicit action in StecStats.
Limited API useConnection checks, Live setup and status, broadcast completion, and selected uploads.
No advertising or saleYouTube API data is not used for advertising, sold, or shared with unrelated third parties.
User-controlled removalDisconnect revokes authorization and removes the stored token; account deletion removes connection data.
